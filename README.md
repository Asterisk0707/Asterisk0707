## About Me

**한국공학대학교 컴퓨터공학부** 3학년 · **백엔드 개발자 지망**

화면 너머에서 서비스가 어떻게 동작하고 데이터가 어떻게 흐르는지 이해하는 개발을 지향합니다.
팀 프로젝트에서는 기능을 만들기 전에 **API와 데이터 구조를 먼저 설계**하고, **팀장·PM으로 일정과 역할을 조율**하며, 필요하면 **Figma로 화면까지 직접 디자인**해 왔습니다.

기타와 음악을 좋아합니다. 매일의 연습이 쌓여 한 곡이 완성되듯, 개발도 꾸준히 쌓아 가겠습니다.
